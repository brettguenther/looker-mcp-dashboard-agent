# Looker Query Vis Config: Single Record

This reference provides visualization options for Single Record elements when building Looker Query JSON payloads (nested under `"vis_config"`).

## Options Reference Table

| Option Key / Path | Type | Label | Description |
| :--- | :--- | :--- | :--- |
| `show_view_names` | `boolean` | `Show Full Field Name` | Toggle controlling visibility of full field names in labels |
